Teacher Console

把教室裡最常用的節奏工具，集中在一個入口。

鐘、抽籤、分組、作業點交、外務登記與留言系統都已先做成獨立頁面，方便投影、平板或電腦直接使用。

萬用鐘

大時鐘、終點倒數、分鐘鬧鐘、碼表與提醒文字區。

開啟工具 抽籤系統

快速號碼抽籤、排除座號、瀏覽器記住設定。

開啟工具 分組系統

名單分組、依組數或人數分配、鎖定與複製結果。

開啟工具 作業點交

紅黃綠狀態、全班快速切換、輸出提醒文字。

開啟工具 外務登記

選外務、選座號、登記離席狀態與返回時間。

開啟工具 留言系統

公開、半匿名、全匿名留言，搭配 Firebase 帳號權限與教師備份。
